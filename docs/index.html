Free open source tool

feedlint-gmc

Validate a Google Merchant Center product feed (CSV or TSV) locally against the rules that get products disapproved, and fix the data before you upload instead of after a rejection.

View source on GitHub

Use it in your browser

Runs fully in your browser, files never leave your device. Drop a CSV or TSV feed file below, or paste its contents, then run the same checks the CLI runs: required attributes, GTIN format, checksum and duplicates, availability and condition values, and placeholder brands.

You can also drag and drop the file anywhere on this panel.
