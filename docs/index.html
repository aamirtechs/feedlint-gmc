Free open source tool

feedlint-gmc

Validate a Google Merchant Center product feed (CSV or TSV) locally against the rules that get products disapproved, and fix the data before you upload instead of after a rejection.

View source on GitHub

What it does

  • GTIN format and mod-10 checksum validation, plus duplicate GTIN detection across the whole feed
  • Required attributes checked per row: id, title, description, link, image_link, availability, price, condition and brand
  • Availability and condition values checked against the allowed Merchant Center values
  • Placeholder brand detection for values such as N/A, Generic and Unknown
  • Writes errors.csv and a Markdown report, and exits with code 1 on errors so it can gate a CI job or a scheduled feed upload

Install and usage

Requires Node.js 20 or later. There are no dependencies to install.

git clone https://github.com/aamirtechs/feedlint-gmc.git
cd feedlint-gmc
node src/cli.js examples/feed.csv --out-dir out

This writes errors.csv and report.md to the output directory. Use --errors FILE and --report FILE to choose exact paths. Exit code is 1 when errors are found and 0 when the feed is clean.
